# Design Backlog

Dispatch source for `/cmux-dispatch`. One Kanban board rendered in ten distinct visual styles; the same realistic board content is owned per entry. Order is user-adjusted (glassmorphism locks the baseline). See `docs/catalog-roadmap.md` for the full direction.

**Status: all ten styles are published — the catalog is complete.** Descriptions mirror `docs/catalog-roadmap.md` (theme/density noted per row). There is no remaining style to dispatch; re-dispatching a published slug would duplicate work.

- [x] `kanban-glassmorphism` — frosted translucent panels over a soft low-chroma mist wash, backdrop blur, cool-gray hairlines, calm dusty-slate accent. light, comfortable
- [x] `kanban-flat-material` — solid color blocks, crisp elevation shadows, bold accents, app-like chrome. light, comfortable
- [x] `kanban-neumorphism` — soft extruded/inset monochrome surfaces, dual light+dark shadows, tactile, low-contrast lifted to AA. light, comfortable
- [x] `kanban-claymorphism` — deep indigo canvas, medium-dark indigo cards/controls, light lavender text, open columns, 6–10px radii, restrained glow. dark, compact
- [x] `kanban-illustration` — chunky illustrated accents, stickers, rounded friendly shapes, doodles, bright palette. light, spacious
- [x] `kanban-editorial` — serif display type, generous whitespace, content-first, restrained print palette, big headings. light, spacious
- [x] `kanban-swiss` — strict grid, austere sans, monochrome with one accent, precise alignment, high craft. light, comfortable
- [x] `kanban-brutalism` — raw monospace, harsh borders, black/white + one accent, exposed grid, high contrast. light, compact
- [x] `kanban-dark-neon` — near-black canvas, glowing neon accents, monospace metrics, terminal/cyberpunk vibe. dark, compact
- [x] `kanban-terminal` — near-black ncurses canvas, full monospace, reverse-video bars, bordered dialog windows, bracketed fields, ANSI semantic colors, F-key status legend. dark, compact
